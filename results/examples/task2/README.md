# Task 2 example outputs

Small, committed snapshots of the Task 2 analysis so teammates can read the
results without running anything. Regenerate everything (including the CSVs,
the annotation template and the PNG figures, which are NOT committed) with:

    python scripts/run_task2.py --config configs/task2.yaml
    python scripts/make_task2_tables.py

Full outputs land in `results/task2/`, which is git-ignored.

`comparison_paper_figures_9_11.md` contains BOTH our generations (`ours:`) and
the completions printed in the TinyStories paper (`paper:`). The `paper:`
columns were extracted from the published PDF and were NOT generated by us.
